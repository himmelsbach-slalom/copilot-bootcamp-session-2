# UI Guidelines

This document describes the core UI interface guidelines for the To-Do app.
It is the primary source for the app’s 80s-themed interface standards.

## Core Style Direction

- Use an 80s-inspired visual theme across the app.
- Apply neon-inspired colors, flashy accents, and a cool retro layout style.
- Keep the experience modern and usable while reflecting classic 80s aesthetics.

## Clarity and Simplicity

- Keep the UI uncluttered with clear spacing and structure.
- Prioritize essential task actions and avoid unnecessary visual noise.
- Use consistent component placement so users can scan screens quickly.

## Button Typography

- Use a cool 80s-style font for button labels.
- Ensure button text remains easy to read at all times.
- Maintain strong contrast between button text and button background.

## Interaction Feedback

- Provide clear visual feedback whenever a button is pressed.
- Use visible state changes (for example: color shift, glow change, or slight depth change).
- Ensure pressed-state feedback is immediate and consistent across all buttons.

## Navigation Pattern

- Apply breadcrumb navigation where applicable.
- Use breadcrumbs on screens where users move through multiple levels or sections.
- Keep breadcrumb labels short, clear, and aligned with page titles.
